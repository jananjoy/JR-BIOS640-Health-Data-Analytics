# BIOS640-Health-Data-Analytics
This repository contains my coursework, R programming exercises, statistical analyses, data visualizations, and reproducible reports developed for BIOS640 – Health Data Analytics.

## Overview

This repository contains coursework, R programming exercises, statistical analyses, data visualizations, and reproducible reports developed for **BIOS640 – Health Data Analytics**.

The repository demonstrates the application of R programming, data wrangling, statistical analysis, data visualization, and reproducible reporting to health-related datasets.

## Repository Structure

```text
JR-BIOS640-Health-Data-Analytics/
│
├── README.md
├── code/
├── data/
├── figures/
├── reports/
└── citations/
```

### `code/`

Contains R scripts and R Markdown files used for data cleaning, analysis, visualization, and report generation.

### `data/`

Contains datasets used throughout the course.

- `raw/` – Original or source datasets
- `cleaned/` – Processed datasets prepared for analysis

### `figures/`

Contains figures and visualizations generated during the analyses.

### `reports/`

Contains completed PDF reports generated from R Markdown analyses. Reports are organized by week or assignment.

### `citations/`

Contains BibTeX references used in R Markdown reports.

## Tools and Technologies

This project uses R, RStudio, tidyverse, ggplot2, dplyr, knitr, kableExtra, R Markdown, and LaTeX for data analysis, visualization, table creation, and reproducible reporting.

| Tool | Purpose |
|---|---|
| R | Statistical computing and data analysis |
| RStudio | Development environment |
| tidyverse | Data manipulation and visualization |
| ggplot2 | Data visualization |

| readr | Data import |

| ggpubr | Publication-ready visualizations |

| knitr | Dynamic report generation |
| kableExtra | Formatting complex tables |
| R Markdown | Reproducible analytical reports |
| LaTeX / PDF | Report generation |

## Reproducibility

The analyses are developed using R and R Markdown. Relative file paths and the `here` package are used where appropriate to support reproducible analysis across different environments.

Reports are generated from R Markdown source files, with supporting datasets, figures, and references maintained within the repository.
